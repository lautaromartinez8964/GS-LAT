# Implementation verification

Version 0.1.0 replayed the empirical two-class, support-entropy, unfloored arm against eight stored development masks and matched all eight pixel for pixel. That check applied only to the entropy-weighted formula and is not a verification of the current package.

Version 0.2.0 set the fusion weight to the geometric support `q`, removed the entropy factor, and retained 50% prior shrinkage. Version 0.3.0 removes that shrinkage and retains the single posterior update and `q` fusion. Automated checks cover the unshrunk, valid-normalized local prior and probability bounds, empirical risk lookup, and connected-component cleanup.

Version 0.3.0 reproduced the archived unshrunk Isan development prediction over all 4,000,000 valid pixels. This checks implementation parity, not independent accuracy, and does not imply parity with masks generated by earlier versions. The checked dependency versions are in `requirements-verified.txt`. Scene data and comparison masks are not included.
